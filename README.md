# OGonline/.github

Organization-wide defaults for OGonline repositories.

- `.github/PULL_REQUEST_TEMPLATE.md`: the default pull request template for every OGonline repository.

GitHub only uses these defaults when a repository has no file of the same type itself. A repository-level PR template (in `.github/`, the root or `docs/`) overrides this default, so remove old repository templates to use the org default.
