# OGonline/.github

Default community health files and templates for the [OGonline](https://www.ogonline.nl) organization.

## How it works

GitHub uses the files in this repository as defaults for every repository in the organization that does not have its own file of the same type. A file in a repository itself (in its root, `.github/` or `docs/` folder) always overrides the default from this repository.

To use an organization default, remove the repository's own version of that file.
