# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in any OGonline project, please report it to us privately.

- **Do not** open a public issue, discussion or pull request for security problems.
- Contact us via the contact details on [www.ogonline.nl](https://www.ogonline.nl).
- Include a description of the issue, the affected project or URL, steps to reproduce and the potential impact.

We will acknowledge your report, investigate it and keep you informed about the progress. Please give us reasonable time to fix the issue before disclosing it publicly.

## Scope

This policy applies to all repositories in the OGonline organization unless a repository provides its own `SECURITY.md`.
